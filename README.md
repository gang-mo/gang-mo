## 🧭 What I Do

- 요구사항을 도메인과 데이터 흐름으로 구체화해 백엔드 기능으로 구현합니다.
- REST/OpenFeign 동기 호출과 RabbitMQ 이벤트 기반 비동기 처리를 목적에 맞게 구분합니다.
- 애플리케이션을 컨테이너화하고 CI/CD를 통해 운영 환경까지 연결합니다.
- 로그·네트워크·권한·배포 버전을 단계적으로 분리해 장애 원인을 좁힙니다.
- 코드·데이터·인프라를 분리된 작업이 아닌 하나의 서비스 흐름으로 바라봅니다.

## 🚀 Selected Projects

### ☁️ [Cloud Infra Project](https://github.com/dushes12/Cloud-Infra-Project) · Full Stack & Infrastructure

스터디룸 예약 MSA의 애플리케이션과 인프라 전 영역을 주도적으로 구현했습니다.

- Spring Boot 기반 Room·Reservation·Notification 마이크로서비스
- OpenFeign 동기 통신과 RabbitMQ 비동기 이벤트 처리
- React·Vite 사용자 화면 및 운영 시연 대시보드
- Docker Compose, Kubernetes, Istio 배포 환경
- Canary 10%·50%·100%, Delay·503 Fault Injection, v1 Rollback 자동화
- Prometheus·Grafana·Kiali 기반 서비스 메시 관측
- GitHub Actions 기반 애플리케이션·컨테이너·배포 선언 CI 검증

### 🦻 [HearO Backend](https://github.com/fourdushes/backend) · DevOps & Backend

음성 기반 의료 서비스에서 백엔드 일부 기능과 AWS 인프라·배포 체계를 담당했습니다.

- AWS EC2·ECR·RDS·S3·IAM 및 GitHub OIDC 구성
- k3s, Traefik, Kubernetes, Argo CD 기반 운영 환경
- 프론트엔드·백엔드·AI 모델 CI/CD와 SHA 이미지 태깅
- GitHub Actions → Amazon ECR → Argo CD GitOps 배포
- STT·S3 권한 및 운영 환경 장애 분석
- Spring Boot, JPA, QueryDSL, Redis, JWT 기반 백엔드 참여

### 🏘️ nextDoor · Backend & AWS Deployment

Spring Boot 백엔드 기능 개발에 참여하고 AWS 환경에 서비스를 배포했습니다.

- Spring Boot, Spring Data JPA, MySQL 기반 기능 개발
- AWS EC2 서버 구축 및 애플리케이션 실행
- 운영 환경 데이터베이스 연결과 서버 접근 설정 점검

### 🍽️ [yaeottae](https://github.com/yangjoonhyung/yaeottae) · Backend

사용자 취향과 리뷰 데이터를 활용한 음식점 탐색 서비스의 백엔드를 개발했습니다.

- 세션·인터셉터 기반 회원 인증과 이메일 인증
- 5단계 사용자 성향 테스트 및 결과 저장
- 음식점 외부 API와 AI 리뷰 예측 서비스 연동
- 리뷰·댓글·신뢰도 기능과 JPA 도메인 설계
- Spring WebFlux 기반 외부 통신과 응답 정규화
